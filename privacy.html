CM YouTube プライバシーポリシー

制定日: 2026年11月3日

「CM YouTube」(以下「本アプリ」)は、運営者が自分の YouTube チャンネルに動画を投稿・管理するための個人用ツールです。本アプリは Google の OAuth 認証を使って YouTube Data API にアクセスします。

1. 取得する情報

本アプリは、利用者が Google アカウントで許可した範囲で、次の情報にアクセスします。

  • YouTube チャンネルの情報(チャンネルID)
  • 本アプリが投稿した動画の情報(動画ID、公開状態、公開予約日時、タグ)

氏名、メールアドレス、連絡先、閲覧履歴などの個人情報は取得しません。

2. 利用目的

  • 動画のアップロード
  • 公開予約日時・サムネイルの設定
  • 投稿済み動画の状態の確認(重複投稿の防止)

3. 保存と管理

認証トークンと投稿記録は、運営者のコンピュータ内にのみ保存します。外部のサーバーには保存しません。

4. 第三者への提供

取得した情報を第三者に提供・販売することはありません。広告にも利用しません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

本アプリは YouTube API サービスを使用しています。YouTube 利用規約とGoogle プライバシーポリシーも適用されます。

6. アクセス権の取り消し

本アプリへのアクセス許可は、Google アカウントのセキュリティ設定からいつでも取り消せます。
